THEME STUDIO - LIVE COMPANION THEME
===================================

This folder is the pre-bundled live companion theme for Instant Theme Changer.

QUICK 1-STEP INSTALLATION:
1. Open Edge or Chrome and go to:
   edge://extensions  (or chrome://extensions)
2. Enable "Developer mode" toggle in the top or side menu.
3. Click "Load unpacked" and select this "live-theme" folder.

DONE!
Now open the Instant Theme Changer extension and click "Connect Included Live Theme" in the Dashboard.
Whenever you click any theme in the extension, the browser tab bar and window frame will update instantly!

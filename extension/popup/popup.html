How to Install Themes from the Extension Folder:
  1. Click Open Extensions below (edge://extensions or chrome://extensions) and switch Developer mode ON.
  2. Click Load unpacked, then open extension/themes/ inside your extension directory.
  3. Select any theme folder (e.g. lilac, aurora, midsummer) — once loaded, clicking that theme or running the timer changes Edge/Chrome's native tab bar instantly.
